**Ряд Тейлора** — это способ заменить сложную, "кривую" [функцию](Функция.md) (вроде [синуса](Тригонометрические%20функции.md), [логарифма](Логарифмические%20функции.md) или [экспоненты](Степенные%20функции.md)) на сумму простых степеней ($x, x^2, x^3...$) путем взятия значения [производной](Производная.md) $n$-ной степени в точке $a$ деленной на $n!$

## Формула Тейлора
Если функция $f(x)$ имеет производные всех порядков в некоторой окрестности точки $a$, то формула Тейлора имеет вид:

$$
f(x) = f(a) + \frac{f'(a)}{1!}(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \dots + \frac{f^{(n)}(a)}{n!}(x-a)^n + R_n(x)
$$

В компактной записи с использованием знака суммы:
$$
f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!} (x-a)^k + R_n(x)
$$

Где:
*   $a$ — точка, в окрестности которой строится ряд (центр разложения).
*   $n!$ — факториал числа $n$.
*   $R_n(x)$ — **остаточный член**, показывающий погрешность приближения функции многочленом $n$-й степени, может быть в форме Лагранжа и Пеано $O((x-a)^n)$.

При $a = 0$ ряд называется **Рядом Маклорена**.

---
## Основные разложения (Ряды Маклорена)
Разложения элементарных функций в ряд Тейлора при $a=0$. Эти формулы часто используются для вычисления пределов и решения дифференциальных уравнений.

| Функция $f(x)$                     | Разложение в ряд                                                                                     | Область сходимости         |     |      |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------- | :------------------------- | --- | ---- |
| **Экспонента** $e^x$               | $\displaystyle 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots + \frac{x^n}{n!} + \dots$             | $x \in (-\infty; +\infty)$ |     |      |
| **Синус** $\sin x$                 | $\displaystyle x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots + (-1)^n\frac{x^{2n+1}}{(2n+1)!} + \dots$ | $x \in (-\infty; +\infty)$ |     |      |
| **Косинус** $\cos x$               | $\displaystyle 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots + (-1)^n\frac{x^{2n}}{(2n)!} + \dots$     | $x \in (-\infty; +\infty)$ |     |      |
| **Логарифм** $\ln(1+x)$            | $\displaystyle x - \frac{x^2}{2} + \frac{x^3}{3} - \dots + (-1)^{n-1}\frac{x^n}{n} + \dots$          | $x \in (-1; 1]$            |     |      |
| **Степенная** $(1+x)^m$            | $\displaystyle 1 + mx + \frac{m(m-1)}{2!}x^2 + \dots + \frac{m(m-1)\dots(m-n+1)}{n!}x^n$             | $x \in (-1; 1)$            |     |      |
| **Геометрическая** $\frac{1}{1-x}$ | $\displaystyle 1 + x + x^2 + x^3 + \dots + x^n + \dots$                                              |                            | x   | < 1$ |

## Остаточный член (Форма Лагранжа)
Для оценки точности приближения используется остаточный член в форме Лагранжа. Существует такая точка $\xi$, лежащая между $a$ и $x$, что:

$$
R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}
$$

Если $\lim_{n \to \infty} R_n(x) = 0$, то ряд сходится к функции $f(x)$ в данной точке.
