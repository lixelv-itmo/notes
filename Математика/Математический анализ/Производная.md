**Производная** [функции](Математика/Математический%20анализ/Функция.md) — это понятие математического анализа, характеризующее скорость изменения функции в данной точке.

Определяется как [[Предел функции|предел]] отношения приращения функции $\Delta y$ к приращению аргумента $\Delta x$, когда приращение аргумента стремится к нулю:

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

Операция вычисления производной называется **дифференцированием**.

## Смысл производной

### Геометрический смысл
Производная функции в точке $x_0$ равна **угловому коэффициенту касательной**, проведенной к графику функции в этой точке. 
$$ f'(x_0) = \operatorname{tg} \alpha = k $$
где $\alpha$ — угол между касательной и положительным направлением оси $Ox$.

### Физический смысл
Если закон движения материальной точки описывается функцией $s(t)$ (путь от времени), то производная пути по времени равна **мгновенной скорости** в момент времени $t$:
$$ v(t) = s'(t) $$
Вторая производная пути (или первая скорости) равна **ускорению**:  $a(t) = v'(t) = s''(t)$.

## Обозначения
Существует несколько способов записи производной:
- **Лагранжа:** $y', \quad f'(x)$ (самое распространенное).
- **Лейбница:** $\frac{dy}{dx}, \quad \frac{df}{dx}$ (удобно в интегральном исчислении).
- **Ньютона:** $\dot{y}, \quad \ddot{s}$ (чаще используется в механике для производной по времени).

## Таблица основных производных
| Функция $f(x)$ | Производная $f'(x)$ |
| :--- | :--- |
| $C$ (константа) | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\operatorname{tg} x$ | $\frac{1}{\cos^2 x}$ |
| $\operatorname{ctg} x$ | $-\frac{1}{\sin^2 x}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ |

## Правила дифференцирования
Пусть $u(x)$ и $v(x)$ — дифференцируемые функции, $C$ — константа.

1.  **Линейность:** $(Cu)' = C u'$
2.  **Сумма/Разность:** $(u \pm v)' = u' \pm v'$
3.  **Произведение:** $(u \cdot v)' = u'v + uv'$
4.  **Частное:** $\left( \frac{u}{v} \right)' = \frac{u'v - uv'}{v^2}$
5.  **Сложная функция (Chain Rule):** $(f(g(x)))' = f'(g(x)) \cdot g'(x)$

## Применение
*   **Исследование функций:** Нахождение промежутков возрастания/убывания и точек [[Экстремум|экстремума]].
*   **Оптимизация:** Поиск наилучших решений (максимизация прибыли, минимизация затрат).
*   **Приближенные вычисления:** Использование [[Дифференциал|дифференциала]] для оценки значений функции.
*   **Физика:** Описание кинематики, скорости, плотности заряда, скорости распада и др.
*   **Машинное обучение:** Градиентный спуск использует производные для минимизации ошибки нейросетей.
