## Определение
**Перегрузка операторов** (Operator Overloading) — это вид полиморфизма, позволяющий изменять поведение стандартных операторов (`+`, `-`, `*`, `<<`, `==` и др.) для пользовательских типов данных (классов и структур).

Это позволяет использовать объекты классов так же естественно, как и встроенные типы (например, `int` или `double`), делая код более читаемым и выразительным.

Синтаксис:
`ReturnType operatorOp(Parameters) { ... }`

---
## Способы реализации

Операторы можно перегружать двумя способами:

1.  **Как метод класса (Member function)**:
    *   Левый операнд — это всегда `*this`.
    *   Используется, когда левый операнд принадлежит нашему классу.
    *   Обязательно для операторов `=`, `[]`, `()`, `->`.
    
2.  **Как внешнюю функцию (Non-member/Friend function)**:
    *   Позволяет получить доступ к приватным полям, если объявлена как `friend`.
    *   Необходима, если левый операнд **не** принадлежит нашему классу (например, `std::cout << obj` или `10 + obj`).

## Примеры реализации

### 1. Арифметические операторы (`+`, `-`)
Допустим, у нас есть класс вектора на плоскости. Мы хотим складывать два вектора: $\vec{c} = \vec{a} + \vec{b}$.

```cpp
class Point {
private:
    int x, y;

public:
    Point(int x = 0, int y = 0) : x(x), y(y) {}

    Point operator+(const Point& other) const {
        return Point(this->x + other.x, this->y + other.y);
    }
    
    int getX() const { return x; }
    int getY() const { return y; }
};

int main() {
	Point p1(1, 2);
	Point p2(3, 4);
	Point p3 = p1 + p2; // x=4, y=6
}
```

### 2. Операторы ввода-вывода (`<<`, `>>`)
Перегружаются **только** как дружественные функции, так как левым операндом является поток (`std::ostream` или `std::istream`), к коду которого у нас нет доступа.

```cpp
#include <iostream>

class Point {
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {}

    friend std::ostream& operator<<(std::ostream& os, const Point& p);
};

std::ostream& operator<<(std::ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

int main() {
	Point p(5, 10);
	std::cout << "Point: " << p << std::endl;
}
```

### 3. Инкремент и декремент (`++`, `--`)
Нужно различать префиксную (`++a`) и постфиксную (`a++`) формы.

```cpp
class Counter {
    int val;
public:
    Counter(int v) : val(v) {}

    Counter& operator++() {
        val++;
        return *this;
    }

    Counter operator++(int) {
        Counter temp = *this;
        val++;
        return temp;
    }
};
```

### 4. Оператор присваивания (`=`)
Один из самых важных операторов при управлении ресурсами (см. Правило трех).

```cpp
class Array {
    int* data;
    int size;
public:

    Array& operator=(const Array& other) {
        if (this == &other) {
            return *this;
        }

        delete[] data;

        size = other.size;
        data = new int[size];
        for (int i = 0; i < size; ++i) data[i] = other.data[i];

        // 4. Возврат ссылки на текущий объект
        return *this;
    }
};
```

## Ограничения и правила
1.  **Нельзя создавать новые операторы**. (Например, нельзя придумать `**` для возведения в степень).
2.  **Нельзя менять приоритет и ассоциативность**. Оператор `*` всегда будет выполняться раньше, чем `+`, даже если они перегружены.
3.  **Нельзя менять количество операндов (арность)**. Бинарный плюс всегда принимает два аргумента.
4.  **Запрещенные к перегрузке операторы**:
    *   `::` (разрешение области видимости)
    *   `.` (доступ к члену)
    *   `.*` (доступ к члену через указатель)
    *   `?:` (тернарный оператор)
    *   `sizeof`, `typeid`

---
## Когда использовать?
*   **Хорошо**: Математические классы (матрицы, векторы, комплексные числа), классы строк, умные указатели (`->`, `*`), итераторы.
*   **Плохо**: Если действие оператора неочевидно. Например, если `a + b` для класса `Player` убивает одного из игроков, это плохой дизайн. Лучше использовать метод `Kill()`.
